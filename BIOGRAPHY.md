## greenServeFE-

One of my notable projects is **greenServeFE-**, which stands for greenServe Fast Execution.

I created greenServeFE- as a virtual-machine-based execution engine for the greenServe programming language.

Instead of relying only on recursive evaluation of the parsed program, greenServeFE- uses a compilation and bytecode execution approach.

The general execution process is:

    .gsve
      |
      v
    Lexer
      |
      v
    Parser / AST
      |
      v
    Compiler
      |
      v
    GSCode bytecode
      |
      v
    Virtual Machine

I built the project around its own bytecode instructions, compiler, runtime values, environments, execution frames, and virtual machine.

The VM supports features including:

- Numbers
- Strings
- Booleans
- Null values
- Arrays
- Objects
- Arithmetic
- Comparisons
- Logical operators
- Assignment
- Indexing
- Object members
- if / else
- while
- for / in
- break
- continue
- Functions
- Recursion
- Captured environments
- Native functions
- Imports
- Bytecode disassembly
- Execution tracing

The project is an independent implementation. Some of its architecture is influenced by ideas commonly used in virtual-machine implementations, such as code objects, instruction streams, constants, names, instruction pointers, operand stacks, frames, and opcode dispatch.

The first release of greenServeFE- was made on **September 28, 2026 at 5:59 PM PDT**.
