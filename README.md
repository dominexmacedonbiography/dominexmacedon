## greenServeFE-

One of my notable projects is **greenServeFE-**.

greenServeFE- is a virtual-machine-based execution engine for the greenServe programming language.

The basic execution process is:

    .gsve
      -> lexer
      -> parser
      -> compiler
      -> bytecode
      -> virtual machine

I built the project to execute greenServe programs through compiled bytecode and a virtual machine.

It includes support for values such as numbers, strings, booleans, null, arrays, and objects, along with arithmetic, comparisons, logical operations, conditionals, loops, functions, recursion, captured environments, native functions, and imports.

The first release of greenServeFE- was made on September 28, 2026 at 5:59 PM PDT.
