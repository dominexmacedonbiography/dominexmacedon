## greenServeFE-

One of my notable projects is **greenServeFE-**, a virtual-machine-based execution engine for the greenServe programming language.

The project takes `.gsve` source code through a lexer and parser, compiles it into bytecode, and executes that bytecode using a virtual machine.

The first release was made on September 28, 2026 at 5:59 PM PDT.
